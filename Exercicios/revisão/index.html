Lógica de Programação

O que é Lógica de programação

Lógica de programação é a base para aprender a programar.
Ela significa organizar e estruturar o raciocínio de forma que um computador consiga entender e executar. <É como montar um passo a passo bem definido para resolver um problema.>

Pra que serve Lógica de programação

A lógica de programação serve para organizar o pensamento e transformar uma ideia em algo que o computador consiga executar.
Sem ela, você até pode aprender comandos de uma linguagem, mas não vai saber como usá-los para resolver problemas de verdade.
